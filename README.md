# Indomito V2

Sitio estatico HTML para Indomito.

## Estructura viva

- `index.html`: indice de navegacion.
- `home.html`: entrada editorial de la V2.
- `carta.html`: carta minimal.
- `servicio.html`: sistema portatil.
- `agenda.html`: eventos.
- `media.html`: sonidos, sesiones y transmisiones.
- `club.html`: TRAZA / club.
- `tienda.html`: tienda.
- `nosotros.html`: origen y contacto.
- `laboratorio.html`: laboratorio.
- `DOCUMENTACION_INDÓMITO_V2.md`: documento de contexto completo.

## Comandos

```bash
npm run build
npm run deploy
```

El build copia las paginas HTML finales a `dist/`. Vercel publica el contenido de `dist/`.
